# Study notes: index

Study notes for the project: concepts, diagrams, and why each technology is used.

**How to read them in VS Code:** open a file and press `Ctrl+Shift+V` (or `Ctrl+K V` for a side-by-side
preview). The diagrams are written in Mermaid; they render in the preview thanks to the
*Markdown Preview Mermaid Support* extension (installed by the dev container).

| File | Read it before... |
|---|---|
| [00-project-objectives.md](00-project-objectives.md) | starting: the goal, what you should learn, why each technology |
| [01-foundations.md](01-foundations.md) | step 1: microservices, HTTP/REST, Spring Boot, IoC/DI, Maven |
| [02-data-layer.md](02-data-layer.md) | steps 2–4: JPA, entities, Spring Data repositories, H2, Lombok |
| [03-web-layer.md](03-web-layer.md) | steps 5–8: REST controllers, testing with a client, Swagger, Spring Data REST |
| [04-layered-architecture.md](04-layered-architecture.md) | steps 9–10: DTOs, mappers, service layer, transactions |
| [05-graphql.md](05-graphql.md) | step 11: GraphQL vs REST, schema, queries and mutations |
| [06-the-bigger-picture.md](06-the-bigger-picture.md) | later: gateway, discovery, config, Keycloak, brokers, Spring AI |

Rule of thumb: read the one section you need right before the step, not everything up front.
Add your own notes at the bottom of each file under **My notes**: writing it in your own words
is what makes it stick.
