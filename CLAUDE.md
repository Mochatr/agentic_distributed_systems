# Working agreement

- This repository is a learning project (microservices with Spring Boot, Spring Cloud, Spring AI).
  Build it **gradually and collaboratively**: one step at a time, explain the why, let the owner
  write or review each piece, and never scaffold a whole project or several steps at once.
- **No AI attribution anywhere in this repository**: no `Co-Authored-By` trailers, session links
  or "Generated with" lines in commits, PR titles/bodies, or code comments.
